OpenMaterials

A versioned map of physics.

OpenMaterials is a typed graph of physical quantities and the formulas that relate them. Representations of 31 scientific codes connect their outputs to its nodes, and values from simulations and measurements attach to those nodes with their provenance and a content hash. Map data is CC BY 4.0 and code is Apache 2.0.

Structure

Each quantity is a typed node. Observables are gauge-invariant, so different codes must agree on them; hidden quantities are gauge-dependent intermediates where codes can differ. An operator computes a quantity from its inputs: formula links carry its symbolic formula, and parameter links supply inputs such as the cell volume. The nodes are grouped into tiers, such as Sources, Harmonic, Transport, Ground state, and Thermochemistry.

A code representation records how one code's outputs map onto these nodes, with units and conventions. Representations exist for kALDo, phono3py, ShengBTE, LAMMPS, GPUMD, Quantum ESPRESSO, VASP, and the other codes on the codes page.

Evidence

Values attach to nodes without changing the graph. A value is a small record: the node, the material, the conditions, the number with its units, and the source. Its id is the SHA-256 hash of the record's lineage object, so the same claim always gets the same id. When values from different methods or codes answer the same question, the agreement page reports their spread.

Protocol

Every node, formula link, and value has a content hash. A change to the graph is appended to map/log.jsonl after the gates check identity, dimensional consistency, connectivity, and duplicates, and after a maintainer reviews it. The map version hashes the head of that log together with the record-format rules, so citing a version pins both.

Contribute a value

A value is one JSON file under docs/data/instances/, in the shape shown here.

  1. 01Write the file by hand, or call omai.map_data.record_instance, which writes it and computes the id.
  2. 02Add it under docs/data/instances/ and open a pull request.
  3. 03CI checks that the node exists on the map and that the id recomputes from the lineage, and a maintainer reviews the source. The map version stays the same, because a value attaches to the graph without editing it.

The paper parser on the playground's Learn tab writes these files from a PDF. The document's appendices cover ingesting a code and extending the DAG, including when to add a node and when to add a parameter.

Governance

OpenMaterials is stewarded by OpenMaterials-AI, a foundation in formation. The initiative holds the map, the protocol, and the openmaterials.ai name, and changes them only through the gated contribution process. The rules are public in GOVERNANCE.md.
