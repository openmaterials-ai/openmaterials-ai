Lean

The map's Lean layer is one package, lean/bridge, pinned to one Physlib revision and one Lean 4 toolchain. It declares the dimension of every map node as a Physlib seven-base ISQ dimension and proves conditional theorems about the map's formulas. The formula bridge lists each theorem with its conditions and evidence.

What is proven, and what is not

A formula counts as proven when a compiled bridge states and proves something about it: that the catalog formula equals a quantity of an actual Physlib model under stated conditions, together with the model's limits, signs and witnesses. The bridge page lists every such theorem, its conditions and its build record.

A closed-form formula is not restated as a theorem. Writing Y = N/D as a hypothesis and concluding Y*D = N, or substituting one definition into another and normalizing, certifies nothing about the physics, so the package contains no such statements. The roadmap marks these formulas as definitions. A theorem about one must state a property, such as a limit, a bound or a reduction to another model.

Each node's dimension is a Physlib Dimension ISQDimensionBase definition over mass, length, time, temperature, amount, current and luminous intensity. These are declarations, not theorems. Nodes with an opaque dimension, such as a potential or a crystal structure, have none.

Limits: a theorem holds for the model and conditions it states. It does not show that a code implements the formula correctly, that a numerical producer converged, or that a value on the map is accurate. The agreement page carries the evidence for those questions.

Reproduce this

Every pull request that touches the bridge, its bindings or its generators rebuilds the package with warnings promoted to errors and checks every binding against the build; each run is public. The commands below are from lean/bridge/README.md.

Rebuild the proofsshell
git clone https://github.com/openmaterials-ai/openmaterials-ai.git
cd openmaterials-ai/lean/bridge

lake exe cache get   # fetch the Mathlib build cache (first build only)
lake build --wfail   # every module; zero errors, zero warnings, no sorry

# check every binding against the build, from the repo root:
cd ../.. && pip install -e . && python -m omai.formula_bindings --check \
  --physlib-path lean/bridge/.lake/packages/physlib --lean-package lean/bridge
