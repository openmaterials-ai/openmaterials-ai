What MACE is

MACE is a family of machine-learned interatomic potentials built on higher-order equivariant message passing. The MACE-MP-0 foundation models, trained on Materials Project trajectories, give energies, forces and stresses across the periodic table without system-specific training. On the map it serves the quantities those models predict.
