What PLUMED is

PLUMED is a library for enhanced sampling and analysis of molecular dynamics. It adds collective variables, metadynamics and related free-energy methods to engines such as LAMMPS, GROMACS and i-PI. On the map it serves the quantities it computes from a trajectory.

In more detail

How a step works

The engine calls PLUMED at three points, at initialization, after each force evaluation and at the end (Tribello 2014). On each call it reads the input as a list of Actions whose dependencies fix the order of evaluation, computes the collective variables and their derivatives with respect to atom positions and cell vectors, evaluates the bias V(s, t), and accumulates the forces on the atoms by running the active Actions in reverse. PLUMED 2 computes the virial of the bias, so it runs at constant pressure as well as constant temperature (Tribello 2014). The same input runs on the fly or on a stored trajectory through the driver tool.

Collective variables and methods

The free energy follows from F(s) = -kB T log P(s) along the chosen variables, and a bias is a function of those variables, so new variables can be assembled in the input with COMBINE, MATHEVAL and the MultiColvar moments without writing C++ (Tribello 2014). Multi-replica schemes (parallel tempering metadynamics, multiple walkers, bias exchange) use MPI (Tribello 2014). Contributed modules add variationally enhanced sampling (VES), the extended-system adaptive biasing force (DRR), experiment-directed simulation (EDS), logMFD, the permutation-invariant vector (PIV), MAZE and PLUMED-ISDB for NMR, SAXS and cryo-EM restraints (PLUMED consortium 2019).

Engines and tools

PLUMED compiles as static object files or a dynamic library (Tribello 2014), and its LGPL license lets it be linked to proprietary codes (PLUMED consortium 2019). The 2019 list of engines is ACEMD, Amber, DL_POLY, GROMACS, LAMMPS, NAMD, OpenMM, ABIN, CP2K, i-PI, PINY-MD and Quantum ESPRESSO, and VMD, HTMD and OpenPathSampling use it for analysis (PLUMED consortium 2019). The plumed executable carries the command-line tools driver and sum_hills and the Lennard-Jones code simplemd (Tribello 2014).

Validation and reproducibility

A regression test suite re-analyzes stored trajectories and must reproduce precomputed results within computational accuracy (Tribello 2014). Documentation is generated from the source with Doxygen, one HTML page per Action with its keywords, so error messages and the manual share one description (Tribello 2014). PLUMED-NEST holds the input files and data behind published simulations, each parsed automatically against the current and the development version, and consortium members commit to deposit the inputs of their papers (PLUMED consortium 2019).
