What pymatgen is

pymatgen is the Python library behind the Materials Project. It handles structures and symmetry, reads and writes the input and output formats of many codes, and provides analysis for phase diagrams, electronic structure and diffraction. On the map it serves the structural and derived quantities it computes.

In more detail

Objects, tests and serialization

pymatgen is object oriented and test driven, and every non-trivial class and method has a unit test. The core package defines Element, Lattice, Site, PeriodicSite, Structure, Molecule and Composition. The entries package wraps a composition and an energy into a ComputedEntry that is independent of whether the energy came from VASP, ABINIT or another code, and ExpEntry holds experimental thermochemistry. Most objects implement to_dict and from_dict, so they round-trip through JSON files or a MongoDB database such as the one behind the Materials Project (Ong 2013).

Thermodynamic analysis

entries.compatibility adjusts GGA+U energies with experimental binary formation enthalpies so they mix with GGA energies, and corrects the overbinding of O2 and N2. MaterialsProjectCompatibility and MITCompatibility carry the two parameter sets. analysis.reaction_calculator balances reactions and computes their energies. The phasediagram package builds compositional and grand canonical hulls. In the Li4SnS4 example one VASP ground-state run plus Materials Project entries gave the Li-Sn-S diagram and a chemical potential map with stability only over a narrow range of Li chemical potential, where a standalone study needs more than 30 structures (Ong 2013).

Interfaces and use in other studies

The io package supports CIF via PyCifRW, molecular formats via OpenBabel, VASP input and output via vaspio with Materials Project parameter sets in vaspio_set, limited Gaussian input, and an aseio adaptor to ASE Atoms. The matproj package talks to the Materials API, a RESTful interface returning JSON for each material (Ong 2013). The DFPT phonon database of Petretto 2018 used pymatgen with AbiPy to generate ABINIT inputs and analyze the results under FireWorks. Sun 2016 retrieved its 29,902 phases from the Materials Project with pymatgen, and Aykol 2018 built its melt-quench workflow on pymatgen, custodian, FireWorks and atomate.
