What Materials Project API is

mp-api is the Python client for the Materials Project, the database of computed properties for inorganic materials. It returns structures, energies above hull, band gaps, elastic tensors and other stored quantities by material id or by query. On the map it serves the quantities it retrieves. It computes none of them.

In more detail

What the Materials Project stores and how it is made

The project computes properties of known inorganic compounds, mostly ICSD structures, with VASP. FireWorks runs the workflows at supercomputing centers and custodian repairs failed runs by rule-based fixes to cluster and convergence parameters, so a metal and an insulator get different workflows without human steps. At publication the database held over 33 000 compounds from over 15 million CPU-hours. Automated checks compare oxidation states, cell volumes and bond lengths with experiment and flag outliers, van der Waals layered compounds for instance, and a Report Issues button collects user corrections (Jain 2013).

The Materials API

The API follows REST principles. Each material is a URL such as materialsproject.org/rest/v1/[unique-id], an HTTP verb acts on it, and the answer is JSON. The project launched it so that users could pull large datasets for data mining or combine local data with the project's, which the web apps cannot serve efficiently. At the time transfer was one way, with two-way submission of structures and experimental data planned. pymatgen carries a high-level interface to the API, and pymatgen-db builds local Materials Project-like MongoDB databases (Jain 2013).

Studies built on the API

Sun 2016 retrieved 29,902 provenance-filtered ICSD phases and found 50.5% metastable with a median of 15 meV/atom and a 90th percentile of 67 meV/atom. Aykol 2018 took every polymorph entry in the database for 41 systems and compared them with ab initio amorphous limits. Bartel 2020 queried all entries with formation enthalpy below 1 eV/atom on July 26, 2019 through the MP API, 85,014 formulas, and noted that the decomposition energies used for training and testing change as new stable materials enter the database.
