What ASE is

ASE, the Atomic Simulation Environment, is a Python library for setting up, running and analysing atomistic calculations. It defines the Atoms object and a common calculator interface that many codes implement, so a workflow can swap the engine without rewriting the script. On the map it appears through the quantities it computes directly from a trajectory or a relaxed structure.

In more detail

Atoms, calculators and communication

The Atoms object holds chemical symbols, Cartesian positions, an optional cell with periodic flags, and per-atom arrays of momenta, magnetic moments and other quantities, all backed by NumPy. A calculator is a black box that returns energy, forces and possibly stress for an Atoms object. Most calculators write an input file, launch the code as a subprocess, wait and parse the output. GPAW, EMT and Asap run inside the Python process with zero-copy data exchange. The CP2K calculator talks over pipes, so the process stays alive between calls (Hjorth Larsen 2017).

Algorithms built on the interface

ase.optimize holds BFGS, L-BFGS, MDMin, FIRE and SciPy optimizers, plus a preconditioned L-BFGS that gave speedups of up to an order of magnitude over plain L-BFGS on solid-state tests, growing with system size. Constraints fix atoms, bond lengths or internal coordinates, and filters expose cell strain so lattice vectors relax with the atoms. ase.md provides velocity Verlet, Berendsen, Langevin and Nose-Hoover thermostats and Berendsen or Parrinello-Rahman pressure control. Saddle points come from NEB, climbing-image NEB, AutoNEB and the dimer method, global minima from basin hopping, minima hopping and ase.ga (Hjorth Larsen 2017).

Vibrations, phonons and thermodynamics

ASE assembles the Hessian from finite-difference forces, 6N + 1 evaluations for N displaced atoms, and imposes momentum conservation to average out egg-box noise from real-space grids. ase.phonons repeats the primitive cell into a supercell and builds the dynamical matrix D(k) from the displaced-atom forces. The paper shows fcc Al from a 7 x 7 x 7 EMT supercell. HarmonicThermo, IdealGasThermo and CrystalThermo give U, S, F and G, and ase.phasediagram draws convex hulls and Pourbaix diagrams from about 500 stored dissolution energies. The BEEFEnsemble class estimates exchange-correlation errors from an ensemble of functionals and works with GPAW and VASP (Hjorth Larsen 2017).

License and use by other codes

ASE is free software under LGPLv2.1 or newer, installs with pip install ase and needs only Python and NumPy, with SciPy and matplotlib recommended. Amp, matscipy, quippy and Atomistica build on the calculator interface (Hjorth Larsen 2017). The SSCHA code uses ASE to call Quantum ESPRESSO, VASP, SIESTA, CP2K or LAMMPS for the forces on its stochastic populations (Monacelli 2021). Oba 2019 fit the anharmonic free energy curves of ScF3 to the Birch-Murnaghan equation of state with ASE to get lattice constants and bulk moduli at finite temperature.
