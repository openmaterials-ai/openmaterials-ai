What reaction-network is

reaction-network builds a graph of possible reactions between phases and searches it for pathways to a target material, ranking them by thermodynamic cost. It is used to plan solid-state synthesis. On the map it serves the reaction quantities it computes.

In more detail

Network model and cost function

Every combination of distinct phases up to size n becomes a reactants node and a products node, and a directed edge joins two nodes whenever a stoichiometrically balanced reaction exists between them. Zero-weight edges loop products back into reactant nodes that contain them, so multi-step pathways appear as walks, and a precursors node and a target node bound the search. Raw Gibbs energies do not work as weights. Negative values create infinite cycles for Dijkstra, kinetic heuristics are excluded, and molar energies scale with stoichiometry. The softplus C = ln(1 + exp((273 K / T) dG)), dG per reactant atom, was chosen over ReLU and piecewise-linear forms (McDermott 2021).

Pathfinding, combinatorics and filters

Yen's algorithm yields k shortest loopless paths to each target from Dijkstra's first path, and pathfinding runs separately toward each product, including byproducts such as CO2. Crossover reactions among the intermediates are computed combinatorially and from the compositional phase diagram, which admits open elements through a grand potential. Steps are combined by solving A m = c with the Moore-Penrose pseudoinverse in SciPy, the total cost is the multiplicity-weighted mean, and interdependent step pairs are consolidated. For N = 76 phases the reaction count grows from about 5.78e3 at n = 1 to 8.56e6 at n = 2 and 5.36e9 at n = 3, so the authors recommend n = 2 (McDermott 2021).

Validation on reported syntheses

For YMnO3 by Li-assisted metathesis the network at 900 K with a 30 meV/atom hull filter gave 20 pathways, and paths 2 and 3 match the observed route through YOCl + LiMnO2, with YOCl, Y3O4Cl, Y2O3 and LiMnO2 all seen in situ. For Fe2SiS4 from iron silicides path 14 is the lowest-cost route containing all observed intermediates FeS2, FeSi and SiS2. For YBa2Cu3O6.5 from BaO2, BaCuO2 appears in 7 of the top 10 paths. For the unsynthesized cathode MgMo3(PO4)3O a network of 21,564 entries and 660,909 nodes produced 2,270 reactions, 186 after a metathesis filter (McDermott 2021).

Dependencies and later versions

Phase diagrams and reaction balancing run on pymatgen, graphs on graph-tool, with Materials Project data version 2020.09.08 (McDermott 2021). Todd 2021 implemented reaction enumeration and ranking by grand potential energy plus total chemical potential distance in the same package, enumerating 3,017 Y2Mn2O7 reactions from 2,878 phases stable at 650 C. McDermott 2023 added a jobflow synthesis planning workflow to the package at materialsproject/reaction-network, with Materials Project version 2022.10.28, a 0.830 eV per CO3 correction for carbonates and selectivity metrics tested on 3520 text-mined literature reactions, of which 82.8% have negative reaction energy.
