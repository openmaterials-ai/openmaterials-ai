What LAMMPS is

LAMMPS is a classical molecular dynamics code for solids, liquids, polymers and soft matter. It ships a large library of interatomic potentials and runs in parallel on CPUs and GPUs. For thermal transport it provides the heat flux, Green-Kubo and nonequilibrium methods. On the map it serves trajectories, correlation functions and the transport quantities built from them.
