What pycalphad is

pycalphad reads CALPHAD thermodynamic databases and computes Gibbs energies, equilibria and phase diagrams from them. It is the computational core for several alloy design and high-throughput thermodynamics workflows. On the map it serves the thermodynamic quantities it evaluates.

In more detail

Models

pycalphad implements the compound energy formalism with sublattices. The default Model exposes GM, SM, HM, CPM, the mixing quantities MIX_GM, MIX_SM, MIX_HM and MIX_CPM, the Curie temperature TC and the degree of ordering DOO as SymPy expressions (Otis 2017). Contributions are declared as a list of (name, method) tuples on the class, so a subclass adds or replaces a term, for example a penalty on the squared deviation from equimolar composition, and is passed as model= to calculate() or equilibrium(), for all phases or per phase as {'FCC_A1': CustomModel} (Otis 2017). Parameter queries run against the Database with tinydb where clauses, and redlich_kister_sum() builds the sums (Otis 2017).

Numerics

calculate() takes T and P as scalars or 1-D arrays and a points array of shape (P, T, y) of site fractions ordered by sublattice and then alphabetically (Otis 2017). equilibrium() always returns GM and MU because the solver needs them, with Phase and NP per vertex of the tie simplex and NaN padding where a phase has fewer internal degrees of freedom (Otis 2017). The authors chose Gibbs energy minimization over the Quickhull approach of the Gibbs package because general convex hull algorithms scale poorly in high dimension and only the lower hull is needed (Otis 2017). Interpolation between computed conditions is not implemented (Otis 2017).

Dependencies and validation

pycalphad depends on numpy, scipy, sympy, xarray, matplotlib, pyparsing, tinydb, autograd, dask and dill, runs on Python 2.7+ or 3.4+ with 2 GB of RAM recommended, and is MIT licensed, with the code on GitHub and version 0.4.2 archived on Figshare (Otis 2017). CI runs tests on every push. They cover property values for several known systems, the equilibrium solver, TDB reading and writing and model construction, and each fixed bug gains a minimal test. About 80% of the code by lines is tested (Otis 2017). Al-Fe was chosen because COST 507 is public and exercises single-sublattice solutions, multi-sublattice ordered phases, magnetic ordering and stoichiometric compounds at once (Otis 2017).
